# CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every pull request and every push to `main` runs `npm run check` in GitHub Actions. Vercel (Git integration) builds previews and production, and production waits for that check.

**Architecture:** One GitHub Actions workflow with one job, `check`. It has no secrets and `contents: read` permission. Deploys are done by Vercel's own Git integration, configured by `vercel.json` (already in the repo). The gate to production is GitHub branch protection plus Vercel Deployment Checks, which Meini configures in her accounts.

**Tech Stack:** GitHub Actions (`actions/checkout@v7`, `actions/setup-node@v7`, `actions/upload-artifact@v7`), Node 22 from `.nvmrc`, Playwright Chromium, actionlint v1.7.12 (run through `go run`, not installed).

**Spec:** `docs/superpowers/specs/2026-09-29-ci-cd-design.md`

## Global Constraints

- The workflow has **no secrets** and `permissions: contents: read` only.
- Triggers: `pull_request` (any branch) and `push` to `main`.
- The job id is exactly `check`, because branch protection and Vercel Deployment Checks refer to it by that name.
- Node version comes from `.nvmrc` (`node-version-file`). It is never hard-coded.
- `VITE_SITE_URL` is **not** set in CI. The unit tests expect the `http://localhost:4173` fallback.
- Nothing is pushed to any remote without Karvin's explicit go-ahead in this session (Task 2, Step 1).
- Git identity is repo-local `karvinnd1207@gmail.com`. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A red check must block the merge and the production deploy.** The workflow alone cannot prove this, because it depends on branch protection and Deployment Checks in Meini's accounts. It is tested by the deliberately failing PR in Task 2, Step 5.
2. **A lockfile that is out of sync with `package.json`** must fail CI loudly at `npm ci`, not install different versions. This is covered by using `npm ci`, and asserted in the Task 1 test.
3. **Two quick pushes to a PR** must not leave two runs fighting over the same ref. The older run is cancelled (`concurrency` with `cancel-in-progress`), which is asserted in the Task 1 test.
4. **When e2e fails in CI,** the Playwright report must be downloadable, so the failure can be debugged without re-running locally. This is the `upload-artifact` step on `failure()`, asserted in the Task 1 test.
5. **The privacy guard must run in the build that Vercel executes,** not only in CI. This was done and verified in the review fix pass (`59604ee`). Task 2, Step 6 confirms it on the real preview build log.

### Task 1: The CI workflow

**Files:**
- Create: `.github/workflows/ci.yml`
- Test: `tests/unit/ci.test.ts`

**Interfaces:**
- Consumes: `npm run check` (`package.json`), `.nvmrc`, `playwright.config.ts` (report dir `playwright-report/`, `reuseExistingServer: !process.env.CI`).
- Produces: a GitHub status check named `check`.

- [ ] **Step 1: Write the failing test**

`tests/unit/ci.test.ts`
```ts
// @vitest-environment node
import { existsSync, readFileSync } from 'node:fs'
import { resolve } from 'node:path'
import { describe, expect, it } from 'vitest'

const file = resolve(import.meta.dirname, '../../.github/workflows/ci.yml')
const yml = () => readFileSync(file, 'utf8')

describe('CI workflow', () => {
  it('exists', () => {
    expect(existsSync(file)).toBe(true)
  })
  it('runs on pull requests and on pushes to main', () => {
    expect(yml()).toMatch(/on:\s*\n\s+pull_request:/)
    expect(yml()).toMatch(/push:\s*\n\s+branches:\s*\[main\]/)
  })
  it('has read-only permissions and no secrets', () => {
    expect(yml()).toMatch(/permissions:\s*\n\s+contents: read/)
    expect(yml()).not.toMatch(/secrets\./)
  })
  it('names the job "check", which branch protection and Vercel refer to', () => {
    expect(yml()).toMatch(/jobs:\s*\n\s+check:/)
  })
  it('cancels an older run on the same ref', () => {
    expect(yml()).toMatch(/concurrency:[\s\S]*cancel-in-progress: true/)
  })
  it('installs exactly the lockfile, takes Node from .nvmrc, and runs the full check', () => {
    expect(yml()).toContain('node-version-file: .nvmrc')
    expect(yml()).toContain('run: npm ci')
    expect(yml()).toContain('npx playwright install --with-deps chromium')
    expect(yml()).toContain('run: npm run check')
  })
  it('uploads the Playwright report when the job fails', () => {
    expect(yml()).toMatch(/if: failure\(\)[\s\S]*actions\/upload-artifact@v7[\s\S]*path: playwright-report/)
  })
})
```

- [ ] **Step 2: Run it to verify it fails**

Run: `npx vitest run tests/unit/ci.test.ts`
Expected: FAIL. `exists` fails, and the others throw `ENOENT` because the file does not exist.

- [ ] **Step 3: Write the workflow**

`.github/workflows/ci.yml`
```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  check:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v7

      - uses: actions/setup-node@v7
        with:
          node-version-file: .nvmrc
          cache: npm

      - run: npm ci

      - run: npx playwright install --with-deps chromium

      # typecheck, lint, unit tests, build (includes the privacy check), build tests, e2e
      - run: npm run check

      - if: failure()
        uses: actions/upload-artifact@v7
        with:
          name: playwright-report
          path: playwright-report
          retention-days: 7
```

- [ ] **Step 4: Run the test and actionlint**

Run: `npx vitest run tests/unit/ci.test.ts`
Expected: 7 passed.

Run: `go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12 .github/workflows/ci.yml`
Expected: no output, exit code 0. (`go run` builds actionlint into the Go module cache for this run only. Nothing is installed on the PATH.)

- [ ] **Step 5: Full suite, commit**

